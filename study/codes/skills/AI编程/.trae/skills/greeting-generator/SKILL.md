# Greeting Generator

## Overview

Greeting Generator 技能用于生成各种场景下的问候语和祝福语，帮助用户快速创建得体、恰当的问候内容。

## Quick Start

使用此技能时，只需提供以下信息：
1. 问候场景（如：日常、节日、商务等）
2. 问候对象（如：朋友、家人、同事、客户等）
3. 特殊要求（如：正式/非正式、简短/详细等）

## Greeting Types

### 日常问候
适用于日常交流中的问候，包括早安、晚安、周末问候等。

**示例：**
- 早安问候："早上好！希望你今天有个美好的开始，充满活力和正能量！"
- 晚安问候："晚安！愿你今晚睡得香甜，明天精神饱满地迎接新的挑战！"

### 节日祝福
适用于各种节日的祝福，包括春节、圣诞节、生日等。

**示例：**
- 春节祝福："新年快乐！愿你在新的一年里身体健康，事业有成，家庭幸福！"
- 生日祝福："生日快乐！愿你在这特别的日子里，所有的愿望都能实现，每一天都充满快乐！"

### 商务问候
适用于商务场合的问候，包括客户问候、合作伙伴问候等。

**示例：**
- 客户问候："尊敬的客户，感谢您一直以来的支持与信任。祝您事业蒸蒸日上，生活美满幸福！"
- 合作伙伴问候："亲爱的合作伙伴，愿我们的合作更加紧密，共同创造更加美好的未来！"

### 特殊场合祝贺
适用于特殊场合的祝贺，包括结婚、升学、晋升等。

**示例：**
- 结婚祝贺："恭喜你们喜结连理！愿你们的婚姻生活美满幸福，白头偕老！"
- 晋升祝贺："恭喜你晋升！你的努力和才华终于得到了认可，祝你在新的职位上取得更大的成就！"

## Resources

### scripts/
包含用于生成问候语的脚本工具。

**现有脚本：**
- `generate_greeting.py` - 根据场景和对象生成个性化问候语

**使用方法：**
```bash
python scripts/generate_greeting.py --scene <场景> --recipient <对象> --style <风格>
```

**参数说明：**
- `--scene`：问候场景（daily, holiday, business, special）
- `--recipient`：问候对象（friend, family, colleague, client）
- `--style`：风格（formal, informal, brief, detailed）
